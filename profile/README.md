# KapraLabs

Kapra is a settlement network. Glow is the private AI client that runs on it.

Keys and private memory stay on the person's device. Servers write blocks. Devices can help confirm the chain. A prompt is $0.002.

The public description, diagrams, and measured results are in **[glow](https://github.com/KapraLabs/glow)**.
